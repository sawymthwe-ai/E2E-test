End-to-End Patient Profile Test Lab

Runs the full patient profile journey in a safe clone of the synthetic data: role review, resolve, role sign-off, gate, doctor approval, discharge document and audit sequence.

What this test proves

Expected outcomes are checked against real application rules, not mock values.

Five synthetic patient profiles cover a happy path, a pharmacist block, a critical safety hold, pending labs and a reportable-disease review.

Each run simulates the signed-in role at every step, verifies that other roles' items stay hidden, and checks the append-only audit sequence in order.

No live data is changed. The test lab works on a deep copy of the synthetic fixture. A run never approves a discharge on behalf of a clinician in the live dashboard.
